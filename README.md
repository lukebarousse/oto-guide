# OTO Guide — multi-team race guide for Outback in the Ozarks

The race guide app for the [Outback in the Ozarks](https://outbackintheozarks.com/) relay — both the **205-mile** (36 legs, Fri–Sat) and the **65-mile** (legs 25–36, Saturday) races. Static frontend on GitHub Pages + a small Supabase database for team data and admin-edited leg content.

**How it works:**

- **Generic guides** anyone can browse: `/` (205) and `/65/` — leg cards with elevation, surface, difficulty, per-leg beta, exchange navigation links, course chart with est. times and night shading, watch how-to, printable version.
- **Team pages**: the race director creates a team in `/admin.html` and sends the captain their link. `/t/<team-slug>` (or `index.html?team=<slug>`) personalizes everything — team name, runners on every leg, filters, pace-based timeline.
- **Team settings** (`/settings.html?team=<slug>`): captains set roster, team size, pace, and who runs which leg (pre-filled by rotation, editable per leg). No accounts — the link is the key.
- **Admin** (`/admin.html`, Supabase login): create/duplicate teams across seasons, assign wave starts, see projected finishes for wave planning, and edit each leg's beta wording + warning flags per season.

## One-time setup (Supabase)

1. Create a project at [supabase.com](https://supabase.com) (free tier).
2. SQL editor → run `supabase/schema.sql`, then `supabase/seed_legs.sql`.
3. Authentication → Providers → Email: **disable sign-ups**; then Users → add the two admin users by hand.
4. Project Settings → API: copy the project URL + `anon` public key into `js/config.js`, commit, push.
5. The `keep supabase awake` GitHub Action pings twice a week so the free project never pauses.

## Development

Everything static is generated by `builder/build.py` from `builder/data.py` (205) and `builder/data65.py` (65 = filtered/rebased 205):

```bash
python3 -m venv .venv && .venv/bin/pip install qrcode pillow
cd builder
../.venv/bin/python build.py                                  # -> out/
OTO_DATA=data65 OTO_OUT=out65 ../.venv/bin/python build.py    # -> out65/
cp out/*.html .. && cp out65/*.html ../65/
```

Runtime pieces (not generated): `js/team.js` (personalization overlay), `settings.html`, `admin.html`, `404.html` (routes `/t/<slug>`), `supabase/*.sql`.
